# 🍽️ Zomato Trends Analysis Dashboard

An interactive **Power BI dashboard** analyzing Zomato restaurant data to uncover trends in ratings, cuisines, pricing, popularity, and city-wise distribution across India.

## 🔍 Key Insights
- Average restaurant rating: **3.89**
- Total restaurants analyzed: **825**
- Popular cuisines: **Beverages, Pizza, Fast Food, Chinese**
- Higher prices do not always mean higher popularity
- Metro cities dominate restaurant availability

## 📊 Features
- Dining vs Delivery rating analysis  
- Cuisine-wise price & popularity trends  
- City and place-level restaurant distribution  
- Interactive filters for cuisine, city, price, and votes  

## 🛠️ Tools Used
- **Power BI**
- **Excel / CSV**
- **Zomato Dataset**

## 🚀 How to Use
1. Open the `.pbix` file in **Power BI Desktop**
2. Use slicers and filters to explore insights
3. Navigate pages using dashboard buttons
